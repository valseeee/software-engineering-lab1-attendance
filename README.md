# 软件工程实验一：Git 与 Codex

本仓库用于完成“软件工具的使用”实验，展示开源项目获取、Git 版本管理、Codex 辅助修改、测试与 GitHub 发布流程。

## 目录

- `attendance_system/`：本次实验使用的 Flask 员工签到系统。
- `signin_system/`：前期用于熟悉 Git 提交与 Python 单元测试的命令行示例。

## 运行签到系统

进入 `attendance_system/` 后，按照其中的 `README.md` 创建虚拟环境、安装依赖并运行 `python app.py`。项目默认使用 SQLite，不需要额外安装数据库。
